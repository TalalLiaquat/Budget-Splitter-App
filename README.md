# 💰 Budget Splitter App

A simple and practical **Budget Splitter** built using Python.
This command-line application helps users divide a bill among multiple people either equally or with custom contributions.

---

## 🚀 Features

* 🔹 Equal bill splitting among all users
* 🔹 Custom split (each person pays a different amount)
* 🔹 Input validation for accurate calculations
* 🔹 Simple and user-friendly CLI interface

---

## 🛠️ Technologies Used

* Python (Core Python)
* Command Line Interface (CLI)

---

## 📌 How It Works

1. Enter the total bill amount
2. Enter the number of people
3. Choose a split method:

   * Equal Split
   * Custom Split
4. View the calculated results instantly

---

## ▶️ Example Usage

```
Enter total bill amount: 1000
Enter number of people: 4

Choose split method:
1. Equal Split
2. Custom Split

Enter your choice: 1

Person 1 pays: 250.00
Person 2 pays: 250.00
Person 3 pays: 250.00
Person 4 pays: 250.00
```
